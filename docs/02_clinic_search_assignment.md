# 担当2: クリニック検索・公式情報整備 実装指示書

## 目的

利用者の希望部位、地域、予算、ダウンタイムに合うクリニック候補を、根拠となる公式情報と一緒に比較できる画面を作る。

## ブランチ

`feature/clinic-search`

作業開始前に `main` を最新化し、このブランチを作成する。`main` へ直接pushしない。

## 担当範囲

- `clinics.html` を新規作成する。
- `clinic-search.js` を新規作成する。
- `clinic-search.css` を新規作成する。
- `data/clinics.js` と `data/clinic-details.js` の項目を整理する。
- 地域、希望部位、予算、ダウンタイムで絞り込めるようにする。
- 医師名、得意分野、資格を表示する。
- 公式症例URL、公式症例件数、集計期間を表示する。
- 公式料金、追加費用、保証、アフターケア、主なリスクを表示する。
- 情報元URLと最終確認日を必ず表示する。
- 不明な情報は推測せず「公式情報で確認できず」と表示する。

## データ登録ルール

- 公式クリニックサイト、公式医師ページ、公式料金表、公式症例ページのみを情報源とする。
- 比較サイト、まとめサイト、SNS投稿だけを根拠にしない。
- 金額には税込・税別、片側・両側、麻酔代などの条件を付ける。
- 症例件数には対象施術と集計期間を付ける。累計か年間か不明な値は登録しない。
- 資格名は公式掲載どおりに記録し、資格から技術力を断定しない。
- URLと `lastVerified` を同時に更新する。

## 推奨データ項目

`id`, `name`, `areas`, `treatments`, `doctors`, `officialCases`, `pricing`, `extraCosts`, `downtime`, `risks`, `aftercare`, `warranty`, `access`, `sources`, `lastVerified`

## 表示ルール

- 「おすすめ順位」ではなく「条件との一致度」として表示する。
- 医療効果や安全性を保証する表現を使わない。
- 料金や症例数が古い場合は警告を表示する。
- 外部リンクは公式サイトであることが分かるラベルを付ける。

## 変更しないファイル

- `server.js`
- `account-store.js`
- `auth-server.js`
- `account-data.js`
- 画像保存関連ファイル

## 完了条件

1. 地域、部位、予算、ダウンタイムの各条件が検索結果へ反映される。
2. 条件に合う登録がない場合、無関係な地域を代替表示しない。
3. 全クリニックに公式URLと最終確認日がある。
4. 医師・症例データに出典がある。
5. 欠損情報を架空の値で補わない。
6. スマホでも比較項目を読める。
7. 既存のシミュレーション画面から移動できる。
8. データ確認方法と変更内容をPRに記載する。

## 提出物

- 検索・詳細画面
- 更新したクリニックデータ
- 出典確認一覧
- 絞り込みの手動テスト結果
