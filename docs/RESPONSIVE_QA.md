# 担当範囲8：画面幅別の表示確認

- 確認日：2026-10-02
- 確認者：Codex（ももか担当作業）
- 作業ブランチ：momoka
- 対象：login.html / app.html、共通ナビゲーション
- 方法：Codex内ブラウザで指定幅の表示を目視確認し、DOMの横方向のはみ出しを測定。

## 結果

| 相当端末 | 幅（CSS px） | ログイン画面 | アプリ画面 | 横にはみ出した要素 |
| --- | ---: | --- | --- | --- |
| PC | 1366 | 確認済み | 確認済み | なし |
| iPhone相当 | 375 | 確認済み | 確認済み | なし |
| Android相当 | 412 | 確認済み | 確認済み | なし |

PCではメニューが横並び、スマホ幅では折り返されることを確認。
長いダミーメールアドレスはスマホ幅で折り返され、ログアウトボタンと重ならない。
Android相当幅で履歴リンクから下部へ移動し、クリニック案内・履歴見出し・ボタンの表示も目視確認。
この確認範囲で本体のHTML/CSS修正は不要。

測定値（documentElement.scrollWidth）はログイン/アプリの順に、
375px幅：360/360、412px幅：397/397、1366px幅：1366/1351。
15pxの差は縦スクロールバーによる表示領域の差。
プレビュー外枠がブラウザより広い場合の外枠の横スクロールと、対象画面自体のはみ出しは区別して確認した。

## 再確認方法

```powershell
node tests/manual/responsive-preview.cjs
```

次のローカルURLを開く。widthには375・412・1366、pageにはlogin・appを指定できる。

```text
http://127.0.0.1:3108/?width=375&page=login
http://127.0.0.1:3108/?width=375&page=app
```

画面上部に測定値と、表示幅からはみ出した要素一覧を表示する。
終了は起動したターミナルでCtrl+C。
この補助サーバーは127.0.0.1にのみ接続を受け付け、本番サーバーの公開対象には含めない。
